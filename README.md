# AIBOOSTER

Продукт, который даёт возможность ускоренно решать многие задачи с помощью AI
в несколько шагов.

## Главное

Перед любой работой над проектом прочитай **[CONSTITUTION.md](./CONSTITUTION.md)** —
свод обязательных правил. Кратко:

- **БД** поднимается сама, без ручного SQL — см. §1.
- **Логи** — единая таблица `app_errors`, чтение через `GET /api/admin/errors` — см. §2.
- **AI** — только через `aimlapi.com`, ключ в `AIMLAPI_KEY` — см. §3.
- **`/admin`** — защищённая страница инспекции схемы и данных БД — см. §4.
- **Тестируй вживую** перед тем, как сказать «готово» — см. §5.
