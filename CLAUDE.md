# Инструкции для AI-агента

**Перед любым действием прочитай `CONSTITUTION.md` в корне репозитория.** Это первый и обязательный шаг для каждого нового чата.

Конституция — единственный источник правды по:

- стеку (Vercel + Neon + TypeScript + AIMLAPI),
- схеме БД, логам (`app_errors`) и админке (`/admin`, `/api/admin/errors`),
- UX Kit (`src/components/ui/`),
- порядку тестирования перед докладом,
- границам автономии агента (порог 70%, что можно делать самому, что — только с подтверждением).

Конституцию не редактируй. Если хочешь изменить — предложи правку отдельным сообщением владельцу.
